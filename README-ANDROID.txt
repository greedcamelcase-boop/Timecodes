ТАЙМКОДЫ ДЛЯ ANDROID — установка на телефон
============================================

Это та же программа, что на компьютере, но в виде приложения для телефона. Она ставится на главный экран из Chrome,
открывается в отдельном окне, работает без интернета, а записи общие с компьютером через синхронизацию Supabase.

Файла .apk здесь нет: для такого приложения он не нужен. Установка идёт прямо из браузера.


ШАГ 1. РАЗМЕСТИ ПРОГРАММУ В ИНТЕРНЕТЕ (бесплатно, один раз)
Чтобы Chrome на телефоне мог установить приложение, его файлы должны лежать на адресе https://.
Самый простой бесплатный вариант — GitHub Pages:
1. Зарегистрируйся на github.com (бесплатно).
2. Создай новый РЕПОЗИТОРИЙ: кнопка «+» → New repository. Назови, например, timecodes. Тип — Public (публичный).
   Для бесплатного аккаунта GitHub Pages работает только с публичными репозиториями.
3. В репозитории нажми Add file → Upload files и перетащи ВСЁ содержимое этой папки:
   index.html, manifest.webmanifest, sw.js и папку icons. Нажми Commit changes.
4. Открой Settings → Pages. В разделе «Build and deployment» выбери Source: Deploy from a branch,
   ветку main и папку / (root), нажми Save.
5. Через минуту-две вверху страницы Pages появится адрес вида  https://ТВОЙ-ЛОГИН.github.io/timecodes/

Публичность не страшна: в файлах нет ни твоих записей, ни ключей. Записи хранятся на телефоне и в твоём проекте Supabase,
а адрес проекта, ключ и код ты вводишь уже в самом приложении. Любой, кто откроет адрес, увидит только пустую программу.
Подойдут и другие бесплатные хостинги статических сайтов (Cloudflare Pages, Netlify): нужно просто выложить эти же файлы.


ШАГ 2. УСТАНОВИ НА ТЕЛЕФОН
1. Открой этот адрес в Chrome на телефоне.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»). На экране появится значок «Таймкоды».
3. Запускай его с главного экрана: окно откроется без адресной строки, как обычное приложение.


ШАГ 3. ВКЛЮЧИ СИНХРОНИЗАЦИЮ С КОМПЬЮТЕРОМ
Сначала на компьютере должна быть настроена синхронизация (см. README.txt в папке для Windows).
На телефоне: значок календаря справа вверху → «Синхронизация между ПК» → введи тот же адрес проекта Supabase, ключ и код,
что на компьютере → «Включить синхронизацию».
Код удобно скопировать на компьютере (окно «Синхронизация» → «Копировать код») и отправить себе в мессенджер.
Записи с компьютера появятся на телефоне, а новые записи с телефона на компьютере.


КАК ПОЛЬЗОВАТЬСЯ НА ТЕЛЕФОНЕ
- Сверху дата и счётчик записей, стрелки ‹ › переключают день, «Сегодня» возвращает к текущей дате.
- Значок календаря открывает календарь на весь экран (там же поиск, синхронизация и резервная копия). Дни с записями подсвечены.
- Значок лупы — поиск по всем датам.
- Строка ввода внизу, прямо над клавиатурой. Клавиатура для таймкода цифровая:
  введи 1.46 (точка вместо двоеточия — это нормально) → кнопка Enter на клавиатуре переведёт в описание → введи описание → Enter сохранит.
  Кнопка «+» сохраняет сразу, в том числе без описания. После сохранения клавиатура остаётся, можно вводить следующий таймкод.
  Для длинных видео: 1.12.35 означает 1:12:35.
- Нажми на запись: под ней появятся кнопки «скопировать таймкод», «скопировать с описанием», «изменить», «удалить».
- Удалил случайно — внизу на несколько секунд появится «Отменить».
- Системная кнопка «Назад» закрывает календарь или окно, а не само приложение.
- Без интернета всё работает: записи сохраняются на телефоне и отправятся на сервер, когда связь появится.


ВАЖНО
- Записи на телефоне хранятся в памяти приложения. Если очистить данные Chrome для этого сайта или удалить приложение,
  локальные записи пропадут. Если синхронизация включена и всё отправлено, их можно вернуть: включи синхронизацию заново.
  Поэтому оставляй синхронизацию включённой, а резервную копию (JSON) делай через «Данные и резервная копия».
- Как обновить приложение: загрузи новые файлы в тот же репозиторий. Телефон подхватит их при следующем запуске
  (может понадобиться закрыть и открыть приложение два раза).
- Если поменяется адрес репозитория, приложение на телефоне нужно поставить заново: данные в нём привязаны к адресу.


ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
- Я проверял эту версию в эмуляции телефона (профиль Pixel 7) в Chromium на компьютере, а не на настоящем Android.
  Не проверялись: вид системной клавиатуры (будет ли строка ввода подниматься над ней), окно установки Chrome,
  поведение кнопки «Назад» на конкретной модели. Если что-то из этого работает не так, напиши, что именно видишь.
- Только Android/Chrome. На iPhone приложение тоже откроется в Safari, но я его там не проверял.
